# Session handoff

- Phiên làm thay đổi repo hoặc trạng thái vận hành phải tạo đúng một file mới tại `.claude_draft/session_handoffs/YYYY-MM-DD-HHmm-<short-slug>.md`.
- Phiên chỉ đọc, khảo sát hoặc hỏi đáp không thay đổi trạng thái thì không tạo handoff.
- Không sửa hoặc tái sử dụng handoff cũ.
- Handoff ghi ngắn gọn: kết quả, kiểm tra đã chạy, việc còn lại, blocker và bước tiếp theo.
- Không chép transcript, output dài hoặc toàn bộ diff vào handoff.
- Handoff không thay thế `log.md`, state, manifest hoặc `decisions.md`.
